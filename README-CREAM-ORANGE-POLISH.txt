CampusFind — Cream + Orange refined theme

This package contains the frontend files with an additional visual polish layer.
The update focuses on a cohesive light cream/orange palette, editorial typography,
softer card surfaces, refined form controls, responsive spacing, focus states, and
subtle motion. Existing HTML and app.js were preserved; no backend was connected.

Run locally:
1. Extract this folder.
2. Open Terminal in CampusFind-Frontend.
3. Run: python3 -m http.server 8001
4. Open: http://localhost:8001

This is a frontend demo. Any backend-dependent features still require their API.
